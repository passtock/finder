# 🧥 Finder (파인더): 타오바오 빈티지 가죽자켓 AI 전수 감정 & 5종 실물도감

타오바오 빈티지 전문 상점(**老咔叽LAOKAJI**)의 대용량 번들 상세페이지(상품당 150~450장 고화질 사진)로부터 **손글씨 실측표 카드를 기준으로 개별 가죽자켓 총 556벌을 정밀 분할 추출**하고, **Qwen-3.8-Flash / DeepSeek-V4.1** 멀티모달 비전 AI를 통해 **브랜드 등급(S/A/B/C), 상태 등급(S/A/B/C), 가죽 상태 상세평가, 실측 치수(어깨, 가슴, 기장, 소매)**를 전수 감정하여 **5종 실물 사진(실측카드 + 정면 + 뒷면 + 목라벨 + 안감/디테일)이 셀 내에 임베딩된 마스터 엑셀 도감**을 생성하는 파이프라인입니다.

---

## 🌟 핵심 구현 및 감정 시스템

### 1. 손글씨 실측표 카드 기준 다중 자켓 구간 분할 (Multi-Jacket Segmentation)
- 1개 타오바오 상품 페이지에 10~45벌의 자켓이 연달아 나열된 대용량 번들 완벽 분할
- **구간 규칙**: `[손글씨 실측 카드 A] -> [정면] -> [뒷면] -> [목/케어 라벨] -> [소매/안감 디테일] -> [다음 실측 카드 B 전까지 = 1벌의 자켓]`
- 36개 상점 폴더 전수 스캔 -> **총 556벌** 완벽 분리

### 2. 5각도 멀티모달 AI 정밀 감정 (5-Angle Vision Appraisal)
- 각 자켓마다 **5장의 핵심 사진(손글씨 실측카드, 정면, 뒷면, 목 라벨, 안감/디테일)**을 AI에 전달하여 4대 지표 평가:
  - **브랜드 등급 (Brand Tier)**:
    - **S등급**: 레더 명가 / 명품 / 하이엔드 (Vanson, Schott, SAINT MICHELLE, Freedom, Belstaff, Renoma 등)
    - **A등급**: 메이저 브랜드 / 인기 아메카지 (Polo Ralph Lauren, COACH, L.L.Bean, BEAMS, GUESS 등)
    - **B등급**: 백화점 신사복 / 클래식 레더 / 도메스틱 (Intermezzo, Maestro, Wind Armor, Morgan, Dayson, Nicole Club, Horn Works 등)
    - **C등급**: 일반 빈티지 가죽 공방 / 무명 오리지널
  - **상태 등급 (Condition Grade)**:
    - **A급**: 가죽 찢김/헤짐 없이 자연스러운 에이징 광택 유지, 보존 상태 우수
    - **B급**: 카라/소매단에 생활 마모나 빈티지 주름이 있으나 착용에 문제없음
    - **C급**: 안감 심한 오염, 깊은 스크래치, 가죽 찢김 등 결함 있음 (예: 안감 오염 쇼트 자켓 등)
  - **상태 상세평가 코멘트**: 가죽 표면 질감, 카라/소매 마모도, 안감 오염/변색 여부 한국어 1~2문장 요약
  - **종합 추천도**: ⭐⭐⭐⭐⭐ 강력추천(S) ~ ⭐⭐ 비추천(C)

### 3. 5종 실물 사진 엑셀 임베딩 (Real 5-Photo Embedded Visual Excel)
- 단순 텍스트/파일명이 아닌, **실제 고화질 썸네일(75x75px) 총 2,780장을 엑셀 셀 내에 직접 삽입**
  - **H열**: 손글씨 실측표 카드 사진
  - **I열**: 자켓 정면 전체 사진
  - **J열**: 자켓 뒷면 전체 사진
  - **K열**: 브랜드 목 라벨 / 상표 사진
  - **L열**: 안감 / 소매 디테일 사진
- 행 높이 65pt, 다크 네이비 헤더(#1E3A8A), 브랜드/상태 등급 컬러 배지 적용
