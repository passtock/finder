# 🧥 Finder (파인더): 타오바오 빈티지 가죽자켓 스크래퍼 & AI 3종 실물도감

타오바오 빈티지 전문 상점(**老咔叽LAOKAJI**)의 대용량 번들 상세페이지(상품당 150~420장 사진)로부터 **각 자켓의 손글씨 실측표 카드를 기준으로 개별 가죽자켓 324벌을 분할 추출**하고, **OpenCode Go x DeepSeek 4.1 Flash** 멀티모달 비전 AI를 통해 브랜드, 가죽 소재, 원산지, 실측치(어깨, 가슴, 기장, 소매)를 클라우드 판독하여 **실측카드 + 자켓 정면 + 브랜드 라벨 3종 실물 사진이 셀 내에 삽입된 엑셀 실물도감**을 생성하는 파이프라인입니다.

---

## 🌟 핵심 구현 기능

1. **손글씨 실측표 카드 기준 다중 자켓 구간 분할 (Multi-Jacket Segmentation)**:
   - 판매자가 1개 상품 페이지에 10~45벌의 자켓을 연달아 업로드하는 패턴 완벽 대응
   - **분할 규칙**: `[손글씨 실측 카드 A] -> [정면 뷰] -> [상세 뷰] -> [목/케어 라벨] -> [다음 실측 카드 B 전까지 = 1벌의 자켓]`
   - OpenCV 경량 기하/밝기 필터링(0.001s) + OpenCode Go AI 검증으로 세탁택 오인식 제로

2. **3종 실물 사진 엑셀 임베딩 (Real 3-Photo Embedded Visual Excel)**:
   - 단순 파일명 텍스트 기재가 아닌, **셀 안에 실제 고화질 썸네일 사진(70x70px) 총 972장 직접 삽입**
   - **C열**: 손글씨 실측표 카드 실물 사진 (70x70px)
   - **D열**: 자켓 정면 실물 사진 (70x70px)
   - **E열**: 자켓 목 브랜드 라벨 / 상표 택 실물 사진 (70x70px)
   - 행 높이 75px, 다크 네이비 헤더(#1F4E79), 정렬 및 테두리 완벽 포맷팅

3. **로컬 CPU 부하 제로 (Zero CPU OCR)**:
   - 고부하 로컬 OCR(Tesseract, ONNX)을 배제하고, OpenCode Go 클라우드 멀티스레드(12 Workers)로 고속 판독 완료
