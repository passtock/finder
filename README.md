## 📁 주요 구성 파일

1. **`opencode_jacket_analyzer.py`**:
   - OpenCode Go API (`deepseek-v4.1-flash`) 연동
   - 로컬 CPU 점유율 0%로 실측표 + 전체 뷰 + 라벨 사진을 초고속 클라우드 판독
   - 결과 파일: `taobao_leather_jackets_with_brands.xlsx`, `taobao_leather_jackets_with_brands.csv`
2. **`taobao_jacket_pipeline.py`**:
   - Chrome 원격 디버깅(`port: 9222`) 연동
   - 타오바오 상세 페이지 30만~40만 px 바닥까지 100% 완전 스크롤 후 고화질 원본 사진 멀티스레드 다운로드
3. **`telegram_remote_bot.py`**:
   - 스마트폰 텔레그램을 통한 원격 크롬 모니터링 및 제어 봇
   - `/status`, `/screen` (캡차 화면 즉시 확인), `/scrape`, `/brand`, `/git` 지원

## 🚀 사용 방법

### 1. 크롬 원격 디버깅 모드 실행
```cmd
launch_chrome_debug.bat
```

### 2. 가죽자켓 스크래퍼 실행
```bash
python taobao_jacket_pipeline.py
```

### 3. OpenCode Go 브랜드 & 실측 클라우드 판독
```bash
python opencode_jacket_analyzer.py
```
